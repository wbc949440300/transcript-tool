# LLM 切星火 + 抖音图文整合（2026-10-31）

## 1. 模型切换：千问 → 讯飞星火 spark-x2.6

`.env` 已切换（千问配置注释保留，可随时回滚）：

```
TRANSCRIPT_LLM_BASE_URL=https://maas-api.cn-huabei-1.xf-yun.com/v1
TRANSCRIPT_LLM_MODEL=spark-x2.6
TRANSCRIPT_LLM_THINKING=off          # 关键
TRANSCRIPT_LLM_TIMEOUT=180
```

**为什么必须 `THINKING=off`**：spark-x2.6 默认开思维链，会把 `max_tokens=512` 全部吃光，
返回**空正文**（实测 14.3s / content=""）。关掉后 2.8s 返回干净 JSON。

### 实测对比（同一输入、同一提示词、同样分块）

| 样本 | 星火（关思考） | 千问 |
|---|---|---|
| 弹道科普 1164 字 | 5.8s / 22 处 | 81.3s / 23 处 |
| 小红书美妆 3424 字 | 9.2s / 16 处 | 140.8s / 19 处 |
| B站数码 679 字 | 2.8s / 3 处 | 40.2s / 3 处 |

星火内部开/关思考（1164 字）：

| | 关思考(512) | 开思考(2048) |
|---|---|---|
| 墙钟 | **5.9s** | 40.2s |
| 替换对 | **34** | 31 |
| completion tokens | 411 | 4514（11 倍） |

结论：**关思考找得更多、快 7 倍、便宜 11 倍**；开思考只在个别生僻专业词的正确写法上更准
（弹线→膛线 vs 弹带；音线→轴线 vs 阴线）→ 用术语表补更划算。

### 术语表（对效果影响最大）

`TRANSCRIPT_LLM_GLOSSARY` 已补充：膛线、轴线、弹带、附面层、膛压、涡流、攻角。

### 生产实测

- 纠错（2 块）：**3.96s**，model=spark-x2.6，4 处改动，零失败
- 笔记（2 块 + 汇总）：**22.7s**，2909 字，13 条要点 / 6 条金句 / 9 个术语

安全：key 已在对话中出现过，建议在控制台轮换。

## 6. 真实图集链接端到端（2026-10-31 补）

用户给的真实分享文案（`https://v.douyin.com/k2m93ih4VIQ/`，`#2024图文伙伴计划`）实测：

```
短链跳转 → https://www.douyin.com/note/7360323126909095219
→ 识别为图集（图文）作品 → FAILURE + 可执行提示（含监听目录路径）
```

过程中发现并修掉两个问题：

1. **图集提示被判成"未知失败"** → `_fetch_platform` 原样重试一次，白多一次页面访问。
   修复：`_PERMANENT_MARKERS` 增加 `图集` / `不支持`（内容类型做不了，不该重试）。
2. **图集链接仍要开浏览器等约 20 秒** → `/note/<id>` 在 `fetch_douyin` 入口就短路，
   直接抛提示，**不再启动 Playwright**。实测从提交到失败约 2 秒。
3. 顺带修：队列提示会滞留在 `errorMessage` 上（RUNNING + "排队中第 1 位" 自相矛盾），
   现在出队时先置为"开始提取..."。

验证：`pytest` **131 项全过**（新增 1 项 `/note/` 短路测试），真实链接 2 秒内返回提示。
