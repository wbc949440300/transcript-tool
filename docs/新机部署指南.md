# 新机部署指南 · 文案提取工具

> 目标：把整个项目文件夹拷到新电脑后，**一条命令配齐环境，启动即用**。

## 前提（只有两件手工活）

1. 装 **Python 3.10+**（推荐 3.11），勾选 "Add to PATH"
2. 把整个项目文件夹（建议连 `wx_dl_pkg/` 一起拷，内含下载器离线安装包 37MB，
   没有它服务会自动从 GitHub 下载，需要网络）

## 一条命令配齐

```powershell
cd 项目路径\transcript_tool
python scripts\setup_new_machine.py
```

自动完成：
- Python 依赖（失败自动换清华镜像重试）
- Playwright 浏览器内核（抖音/小红书渲染通道需要，约 130MB）
- ffmpeg：系统没有就自动下载到项目内 `tools/ffmpeg`（`run.py` 会优先使用，不污染系统 PATH）
- `.env`：不存在则从 `.env.example` 创建

只检查不改动：`python scripts\setup_new_machine.py --check`

## 启动

```powershell
python run.py
```

启动时全部自动就位（无需任何手工配置）：

| 组件 | 行为 |
|---|---|
| wx_channels_download | 未安装 → 自动安装（本地包优先/否则 GitHub）→ 自动启动（免管理员） |
| 监听目录 | 从未设置过 → 自动接线下载器的下载目录 |
| whisper 模型 | 首次使用自动下载（默认走 hf-mirror 镜像） |
| 历史库 / 任务目录 / 下载目录 | 自动创建 |

## 可选手工项

- **AI 纠错 / 生成笔记**：编辑 `.env` 填 `TRANSCRIPT_LLM_API_KEY`（不填其余功能全部正常）
- **小红书**：把登录 cookie 放 `cookies/xiaohongshu.txt`（多数笔记需要登录态）
- **视频号首次使用**：若页面显示"MITM 证书未安装"，点一次「修复证书（管理员）」或
  「一键安装并启动」（弹 UAC 点"是"），之后免管理员自动启动
- **GPU 转写**：需要 NVIDIA 显卡 + `pip install nvidia-cublas-cu12 nvidia-cudnn-cu12`；
  没有显卡会自动回退 CPU（慢 ~10 倍）

## 常见问题

| 现象 | 处理 |
|---|---|
| 下载器自动安装失败（GitHub 不通） | 把旧机的 `wx_dl_pkg/*.zip` 拷过来，重启服务即可离线装；或页面上点「一键安装并启动」 |
| 提示"MITM 证书未安装" | 页面点「修复证书（管理员）」，UAC 点"是"，一次即可 |
| whisper 模型下载慢/失败 | 确认走默认 hf-mirror（run.py 已设）；或手动设 `HF_ENDPOINT` |
| ffmpeg 下载失败 | 手动下载 essentials 版，解压 bin 到 `tools/ffmpeg/bin` |
