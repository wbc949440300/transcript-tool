## 1. 还缺的两件事（都是"人出面"，不是写代码）

### 1.1 代理出口（每个平台一条国内出口）

**代码已就绪**（`app/utils.py`）：

```
TRANSCRIPT_PROXY_POOL=host1:8080,host2:8080            # 所有平台共享的池
TRANSCRIPT_PROXY_POOL_DOUYIN=ip1:8080,ip2:8080         # 抖音专用池
TRANSCRIPT_PROXY_POOL_KUAISHOU=...                     # 快手专用池
TRANSCRIPT_PROXY=http://127.0.0.1:7891                 # 或单条固定出口
TRANSCRIPT_PROXY_MEDIA=...                             # 媒体 CDN 是否也走代理（默认直连）
```

- 出口按"平台 + 出口"记录冷却/额度（`platform:<平台>@<出口>`），一条出口被限不影响另一条
- 启动时会自检配置的出口（`main.py` 的 proxy self-check，日志见 `app.log`）
- 抓取链路是**显式代理**：不配就是家宽直连，**不受系统代理影响**（所以 FlClash 用国外节点与它互不干扰）

**买什么（三条硬要求）**：
1. **国内出口**（境外节点与"账号常用地"矛盾，反而更容易触发风控）
2. **IP 长期固定**（每次请求换 IP 的短效代理比不用更危险；一个账号要稳定在一个出口上活动）
3. **独享/静态优先**（共享 IP 池基本已被平台标记）；协议优先 **http/https**（本机没装 PySocks，socks5 走不了 urllib 那条链路）

**三条低成本路线**（详见 `docs/账号池与代理池-2026-10-31.md`）：
1. 在 mihomo/Clash.Meta 里**单开一个监听端口**（如 7891）钉死在某个国内节点 → `TRANSCRIPT_PROXY=http://127.0.0.1:7891`
2. 买国内住宅代理（按 IP 或流量计费）
3. 多拨/多条宽带（零成本土办法，但出口数有限）

### 1.2 账号池（抖音 3~4 个号）

**代码已就绪**：账号池（`cookies/<平台>/account_N.txt` + 每账号独立浏览器 profile）、
轮换、账号级冷却、**每账号每日上限 `TRANSCRIPT_ACCOUNT_DAILY_MAX=30`**（超限会在任务错误里提示"要跑更多请加号"）。

**配比规则：1 个账号 : 1 条出口**

| 目标量/天（抖音） | 账号数 | 出口 |
|---|---|---|
| ≤30 条 | 1 个够（匿名也行；今天实测 20 条零风控） | 可以不配 |
| 30~80 条 | 1~2 个 | 1~2 条 |
| 80~150 条 | 3~4 个 | 3~4 条 |

**当前 `.env` 的额度**：全局 1200、抖音 600、快手 400、小红书 150、B站 200、每账号 30/天
→ 抖音 600/天需要 **20 个账号位**才撑得满，实际建议先按"3~4 个号 × 30 = 90~120 条/天"起步。

**怎么登录**：页面「账号」页 → 抖音 → `+ 新账号 account_1` → 弹浏览器人工扫码；
抓取端读的是**同一个** profile（命名一致性有单测保证），不会"登录了却没用上"。

**当前登录状态**：抖音 1 个（默认）、小红书 1 个；快手不需要；B站未登录。

**分发到别的电脑**：不要拷 `cookies/`，每台机器各自登录自己的号（一个账号只在一台机器上用）。

> 向公司申请账号/代理时，直接用 `docs/账号与代理申报说明.md`。

## 3. 踩过的坑（后人直接避雷）

| # | 坑 | 教训 |
|---|---|---|
| 1 | 函数内局部 `import` 遮蔽模块级名字（`_referer_for`）→ `UnboundLocalError` | 改完必须真跑一次任务，不能只看编译过 |
| 2 | 缺导入（`time` / `json` / `Path` / `os`）→ 被 `except` 吞掉，静默失效 | 每次收尾跑静态扫描（本项目有脚本） |
| 3 | B站 `subtitles` 里可能是 **danmaku 弹幕 XML** 且 CDN 用 **raw deflate** 压缩 | 字幕要按语言键过滤 + 解码 + 文本校验，否则乱码当文案 |
| 4 | 抖音**低码率档直链下到的文件 ffprobe 读不出流** | 候选要有验证 + 回退默认档 + 记忆 |
| 5 | 小红书图文会抓到**推荐流里别人的封面** | 选择器要限定正文容器；停止阈值别太激 |
| 6 | Windows 上 `Path.replace` 偶发 `WinError 32`（文件被占） | 唯一 tmp 名 + 专用锁 + 重试 |
| 7 | 计划任务用 `python.exe` → **每 5 分钟闪一次黑窗** | 用 `pythonw.exe`；脚本在无 stdout 时不能加 StreamHandler |
| 8 | `schtasks /tr` 会把路径里的 `\t` 当**制表符**（`transcript_tool`） | 用 PowerShell `New-ScheduledTaskAction` 注册，或注册后用 `/query /v` 核对参数 |
| 9 | 多会话并行时互相**重启服务**，把长跑测试的会话冲掉 | 长跑要能跟随重启（重登 + PID 记录） |
| 10 | `.env` 里的真 key 被**测试进程**读到 → 测试真往微信推消息 | conftest 里把告警通道全部关掉 |
| 11 | 全角/半角括号不一致（`(默认)` vs `（默认）`） | 前端/后端共用的字面量要统一，测试要断言它 |
| 12 | 抖音页面**永远**带 `captcha`/`verify` 字样 | 风控判定只看 URL 与接口状态，不看页面文本 |
