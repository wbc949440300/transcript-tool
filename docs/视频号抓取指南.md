# 视频号 → 文案：抓包导出 + 自动监听转写

> 视频号（微信视频号 / Channels）没有公开的网页接口，服务器端无法直接解析。
> 本文给出**在本机完成**的完整链路：抓包工具导出视频 → 本工具自动监听 → 转写 → 导出文案。

## 一、为什么不能像抖音那样直接贴链接

| 平台 | 网页可解析 | 说明 |
|---|---|---|
| 抖音 | ✅ | 详情接口 + Playwright 渲染 |
| B站/小红书/YouTube | ✅ | yt-dlp 提取器 |
| **视频号** | ❌ | 微信封闭生态，视频流需微信客户端环境（`channels.weixin.qq.com` 页面只有空壳 SPA） |

参考项目 vidknot 的结论一致：「视频号**无任何自动化下载路径**」。

## 二、推荐方案：抓包导出 + 自动监听

### 步骤 1：准备一个"收件箱"目录

```
D:\Downloads\vidknot-inbox
```

（任意路径都行，建议单独建一个空目录）

### 步骤 2：用抓包工具导出视频号视频

可选工具（都是第三方，自行安装）：

- **Res-downloader**（开源，图形界面，支持视频号/抖音等）
- **putyy 系下载器**
- Fiddler / mitmproxy（技术向，需自行配置证书）

要点：

1. 工具首次使用需要安装根证书并开启系统代理
2. 在微信里**打开要处理的视频号视频**并播放几秒（触发视频流）
3. 在抓包工具的资源列表里找到该视频 → **下载/导出**
4. 把导出目录**指向步骤 1 的收件箱**

### 步骤 3：在本工具里开启"自动监听文件夹"

打开「视频号视频文案提取」页面 → 找到 **自动监听文件夹** 卡片：

1. 填入收件箱路径：`D:\Downloads\vidknot-inbox`
2. 点 **开始监听**
3. 之后抓包工具每导出一个视频，本工具会自动：
   - 检测文件（等待写入完成，避免半截文件）
   - 创建转写任务（默认 medium 模型，GPU 加速）
   - 结果进入「历史记录」，可直接导出 TXT/MD/Word/Excel/SRT
   - 把已处理文件移动到 `收件箱\processed\`（可关闭）

### 步骤 4：取结果

- 页面「历史记录」→ 找到自动导入的记录 → 查看 / 导出
- 需要更准确的用词时，点 **AI 纠错**（智谱 GLM-4-Flash）

## 三、命令行方式（可选）

也可以直接用 API：

```bash
# 开启监听
curl -X POST http://127.0.0.1:8000/prod-api/watch/start \
  -H "Content-Type: application/json" \
  -d "{\"dir\":\"D:/Downloads/vidknot-inbox\",\"model\":\"medium\",\"interval\":5,\"moveDone\":true}"

# 查看状态
curl http://127.0.0.1:8000/prod-api/watch/status

# 停止
curl -X POST http://127.0.0.1:8000/prod-api/watch/stop
```

或写进 `.env`，服务启动时自动开启：

```
TRANSCRIPT_WATCH_DIR=D:/Downloads/vidknot-inbox
TRANSCRIPT_WATCH_MODEL=medium
TRANSCRIPT_WATCH_INTERVAL=5
TRANSCRIPT_WATCH_MOVE=1
```

## 四、备选方案（不想装抓包工具）

1. **微信内保存**：部分视频号作品支持"保存视频"到手机相册 → 传到电脑 → 上传转写
2. **手机录屏**：录屏后上传（音轨会被提取转写）
3. **系统音频录制**：播放时录系统声音，导出 wav → 上传（需启用"立体声混音"设备）

## 五、注意事项

- 抓包工具需要安装根证书，会接管系统 HTTPS 流量；**用完建议关闭代理并移除证书**
- 只处理你有权访问、有权转写的内容；不要用于传播他人作品
- 视频号视频多为加密/混淆缓存，**不要试图从微信缓存目录直接提取**（实测 `msg\video` 为空）
- 抓包工具的导出目录里若混有非媒体文件，本工具会自动忽略
